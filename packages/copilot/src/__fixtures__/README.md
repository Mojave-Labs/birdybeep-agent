# Copilot CLI hook fixtures

These are privacy-redacted payloads captured from real GitHub Copilot CLI 1.0.70 runs on
2026-08-06 using a loopback OpenAI-compatible BYOK provider with all GitHub credentials unset.
Field names and value types are unchanged; paths, session ids, prompts, command text, and command
output are deterministic synthetic replacements. Copilot emits the event name only through the
configured hook key, not inside these camelCase payloads.
